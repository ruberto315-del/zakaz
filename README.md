# Telegram Shop Bot

Telegram бот для інтернет-магазину з повним функціоналом управління товарами, замовленнями та оплатою.

## Функціонал

### Для користувачів:
- 🛍️ Каталог товарів з фото та описами
- 🛒 Корзина з можливістю зміни кількості
- 📦 Оформлення замовлення зі збором контактних даних
- 📸 Прикріплення чека про оплату
- 📋 Система предзаказів
- 📊 Перегляд статусів замовлень (клієнтський кабінет)
- 🔔 Push-сповіщення про зміни статусів
- 📞 Зв'язок з адміністратором
- ❓ FAQ

### Для адміністратора:
- ➕ Додавання товарів
- ✏️ Редагування товарів (назва, опис, ціна, фото)
- 💰 Зміна цін
- ✅ Управління доступністю товарів
- 📊 Перегляд та управління замовленнями
- 🔄 Оновлення статусів замовлень
- 📋 Управління предзаказами
- ❓ Керування FAQ

### Додатково:
- 💳 Інтеграція з LiqPay для оплати (опціонально)

## Встановлення

1. Клонуйте репозиторій або завантажте файли

2. Встановіть залежності:
```bash
pip install -r requirements.txt
```

3. Налаштуйте конфігурацію в `config.py`:
   - Токен бота вже встановлено
   - ID адміністратора вже встановлено
   - Для LiqPay (опціонально) створіть файл `.env`:
     ```
     LIQPAY_PUBLIC_KEY=your_public_key
     LIQPAY_PRIVATE_KEY=your_private_key
     ```

4. Запустіть бота:
```bash
python main.py
```

## Використання

### Для користувачів:

1. Запустіть бота командою `/start`
2. Оберіть "🛍️ Каталог товарів" для перегляду товарів
3. Додайте товари до корзини
4. Оформіть замовлення через "🛒 Корзина"
5. Введіть контактні дані та адресу доставки
6. Оберіть спосіб оплати (LiqPay або прикріпіть чек)

### Для адміністратора:

1. Запустіть бота командою `/start` (автоматично відкриється адмін-панель)
2. Додайте товари через "➕ Додати товар"
3. Редагуйте товари через "📝 Редагувати товар"
4. Переглядайте та обробляйте замовлення через "📊 Замовлення"
5. Оновлюйте статуси замовлень (користувачі отримають сповіщення)

## База даних

Бот використовує SQLite базу даних `shop_bot.db`, яка створюється автоматично при першому запуску.

Таблиці:
- `users` - користувачі
- `products` - товари
- `cart` - корзина
- `orders` - замовлення
- `order_items` - позиції замовлень
- `preorders` - предзакази
- `faq` - часті питання

## LiqPay інтеграція

Для використання LiqPay:

1. Встановіть бібліотеку:
```bash
pip install liqpay
```

2. Додайте ключі в `.env` файл або безпосередньо в `config.py`

3. Налаштуйте callback URL на вашому сервері (якщо потрібно)

## Статуси замовлень

- ⏳ Очікує обробки (pending)
- 🔄 В обробці (processing)
- ✅ Готове до відправки (ready)
- 🚚 Відправлено (shipped)
- 📦 Доставлено (delivered)
- ❌ Скасовано (cancelled)

## Примітки

- Бот автоматично відправляє сповіщення користувачам при зміні статусу замовлення
- Всі дані зберігаються локально в SQLite базі даних
- Для продакшн використання рекомендується використовувати PostgreSQL замість SQLite
