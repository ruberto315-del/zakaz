# Telegram Shop Bot

Telegram бот для інтернет-магазину з повним функціоналом управління товарами, замовленнями та оплатою.

## Функціонал

### Для користувачів:
- 🛍️ Каталог товарів з фото та описами
- 🛒 Корзина з можливістю зміни кількості
- 📦 Оформлення замовлення зі збором контактних даних
- 📸 Прикріплення чека про оплату
- 📋 Система предзаказів
- 📊 Перегляд статусів замовлень (клієнтський кабінет)
- 🔔 Push-сповіщення про зміни статусів
- 📞 Зв'язок з адміністратором
- ❓ FAQ

### Для адміністратора:
- ➕ Додавання товарів
- ✏️ Редагування товарів (назва, опис, ціна, фото)
- 💰 Зміна цін
- ✅ Управління доступністю товарів
- 📊 Перегляд та управління замовленнями
- 🔄 Оновлення статусів замовлень
- 📋 Управління предзаказами
- ❓ Керування FAQ

### Додатково:
- 💳 Інтеграція з LiqPay для оплати (опціонально)

## Встановлення

### Локальна розробка

1. Клонуйте репозиторій або завантажте файли

2. Встановіть залежності:
```bash
pip install -r requirements.txt
```

3. Налаштуйте конфігурацію:
   - Токен бота вже встановлено в `config.py`
   - ID адміністратора вже встановлено
   - Для локальної розробки створіть файл `.env`:
     ```
     USE_POSTGRES=false
     BOT_TOKEN=your_bot_token
     ADMIN_ID=your_admin_id
     LIQPAY_PUBLIC_KEY=your_public_key
     LIQPAY_PRIVATE_KEY=your_private_key
     ```

4. Запустіть бота:
```bash
python main.py
```

### Деплой на Railway

1. Підключіть ваш GitHub репозиторій до Railway

2. Додайте PostgreSQL базу даних в Railway

3. Налаштуйте змінні оточення в Railway:
   - `BOT_TOKEN` - токен вашого Telegram бота
   - `ADMIN_ID` - ID адміністратора
   - `USE_POSTGRES=true` - використовувати PostgreSQL
   - `DATABASE_URL` - Railway автоматично надає цю змінну при підключенні PostgreSQL
   - `LIQPAY_PUBLIC_KEY` та `LIQPAY_PRIVATE_KEY` (опціонально)

4. Railway автоматично визначить Python проект і встановить залежності з `requirements.txt`

5. Бот автоматично запуститься після деплою

## Використання

### Для користувачів:

1. Запустіть бота командою `/start`
2. Оберіть "🛍️ Каталог товарів" для перегляду товарів
3. Додайте товари до корзини
4. Оформіть замовлення через "🛒 Корзина"
5. Введіть контактні дані та адресу доставки
6. Оберіть спосіб оплати (LiqPay або прикріпіть чек)

### Для адміністратора:

1. Запустіть бота командою `/start` (автоматично відкриється адмін-панель)
2. Додайте товари через "➕ Додати товар"
3. Редагуйте товари через "📝 Редагувати товар"
4. Переглядайте та обробляйте замовлення через "📊 Замовлення"
5. Оновлюйте статуси замовлень (користувачі отримають сповіщення)

## База даних

Бот підтримує два типи баз даних:

### PostgreSQL (рекомендовано для продакшн)
- Використовується на Railway та інших хостингах
- Автоматично підключається через `DATABASE_URL` змінну оточення
- Підтримує connection pooling для кращої продуктивності

### SQLite (для локальної розробки)
- Використовується локально для розробки
- База даних `shop_bot.db` створюється автоматично при першому запуску
- Встановіть `USE_POSTGRES=false` в `.env` для використання SQLite

Таблиці:
- `users` - користувачі
- `products` - товари
- `cart` - корзина
- `orders` - замовлення
- `order_items` - позиції замовлень
- `preorders` - предзакази
- `faq` - часті питання

## LiqPay інтеграція

Для використання LiqPay:

1. Встановіть бібліотеку:
```bash
pip install liqpay
```

2. Додайте ключі в `.env` файл або безпосередньо в `config.py`

3. Налаштуйте callback URL на вашому сервері (якщо потрібно)

## Статуси замовлень

- ⏳ Очікує обробки (pending)
- 🔄 В обробці (processing)
- ✅ Готове до відправки (ready)
- 🚚 Відправлено (shipped)
- 📦 Доставлено (delivered)
- ❌ Скасовано (cancelled)

## Примітки

- Бот автоматично відправляє сповіщення користувачам при зміні статусу замовлення
- На Railway автоматично використовується PostgreSQL через змінну `DATABASE_URL`
- Для локальної розробки можна використовувати SQLite (встановіть `USE_POSTGRES=false`)
- Connection pooling використовується для PostgreSQL для кращої продуктивності
